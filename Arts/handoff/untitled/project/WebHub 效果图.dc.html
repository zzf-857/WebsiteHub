详细介绍

Unity Documentation 是 Unity 引擎的官方文档站点，由两部分组成：Unity 手册（Manual）介绍编辑器界面、资源管线、物理、渲染与构建发布等功能；脚本 API（Scripting Reference）逐条列出 UnityEngine 与 UnityEditor 命名空间下的类、方法、属性和事件，并附带 C# 示例代码。

文档支持按 Unity 版本切换（2021 LTS 至 Unity 6），并提供中文等多语言界面。查 API 时建议直接使用站内搜索或以「类名 + 方法名」为关键词，例如 Rigidbody.AddForce。

与 Unity Learn（教程）和 Unity Discussions（社区问答）搭配使用，可以覆盖从入门学习到疑难排查的完整链路。
