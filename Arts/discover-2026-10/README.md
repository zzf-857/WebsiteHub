# 发现页方向稿（2026-10）

三个方向用同一批收藏内容绘制，供构图参考；在线画布：https://claude.ai/artifact/AddFgTBwxvzzaJ9942ketn

| 文件 | 方向 | 用在哪里（2026-10 D5 决策） |
| --- | --- | --- |
| `B-Gallery.dc.html` | 暗室画廊：封面优先、瀑布流、悬停揭示、重温主视觉 | **发现页（首页）的构图**，用现有令牌落地，浅深主题都要成立 |
| `A-Tool.dc.html` | 克制工具：沿用现有令牌的统一网格卡片 | **收藏库管理模式**、收件箱等高密度页面 |
| `C-Editorial.dc.html` | 瑞士编辑：大字标题、细线分隔、按主题聚类 | Agent 推送的**每周重温周刊** |

注意：

- 稿中颜色是方向示意。落地时颜色一律来自 `apps/web/app/globals.css` 的设计令牌（1f 规范板），新增的封面类令牌也写在那里。
- 斜线占位代表真实网页预览图或视频封面；其余封面是“生成封面”（仓库 / 要点 / 站点），正是 D4 的落地方案。
- 卡片数据是示例：部分来自用户真实收藏截图，星数、收藏天数等为示意。
- 这些文件依赖设计画布运行时，不能在仓库里直接打开渲染，只作为构图与尺寸参考。
