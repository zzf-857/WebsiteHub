WebHub

把正在看的网页一键收藏到你的 WebHub。

填网站首页地址即可；本机开发用 http://localhost:3100。

这是明文 HTTP 地址，令牌会不加密地经过网络。建议改用 Tailscale 提供的 https 地址。

在 WebHub「设置 → Agent 接入」创建读写令牌后粘贴到这里；只读令牌不能收藏。 令牌只保存在本机浏览器，不会同步到云端。

打开 WebHub 的 Agent 接入设置

怎么收藏

  • 点击浏览器工具栏上的 WebHub 按钮。
  • 快捷键 Alt+Shift+S（可在浏览器的扩展快捷键设置里修改）。
  • 在页面或链接上点右键，选「收藏到 WebHub」。

按钮上的标记：✓ 已收藏，= 之前收藏过，! 没有成功（系统通知会说明原因）。 收藏后 WebHub 会在一两分钟内自动补全简介、分类和封面。
